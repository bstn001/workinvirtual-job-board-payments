# Security Policy

## Supported version

Security fixes are provided for the latest released Lite version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email **support@workinvirtual.com** with:

- the affected version;
- reproduction steps;
- impact and attack prerequisites;
- a minimal proof of concept, if safe;
- any suggested mitigation.

Remove live Stripe credentials, personal data, and real payment information. We will acknowledge a complete report as soon as practical and coordinate remediation and disclosure.
