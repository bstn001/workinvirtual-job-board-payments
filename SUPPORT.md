# Support

Use the right channel so requests can be handled efficiently:

- Documentation: https://workinvirtual.com/docs/stripe-job-board-payments/
- Reproducible Lite bug: GitHub Issues
- Lite feature proposal: GitHub Discussions or Issues
- Setup and account support: support@workinvirtual.com
- Private security report: follow SECURITY.md
- Professional product support: https://workinvirtual.com/contact-us/

Never post Stripe keys, webhook secrets, customer information, or complete payment payloads publicly.
